# JRA Prediction Engine Ver.2.49 LIVELOG BETFORM v8

Ver.2.49 LIVELOG BETFORM v7をベースに、結果・払戻の自動照合を改良した版です。

## 今回の追加・修正
- netkeibaの `Payout_Detail_Table` を優先して払戻テーブルを全件取得
- これまで欠落することがあった2つ目の払戻テーブルのワイド・馬単・3連複・3連単も取得対象化
- ワイド・複勝など、1行に複数の組合せと払戻額が入る券種を1点ずつ対応付け
- ワイド `15-14` と払戻 `14-15` のような順不同買い目を同一判定
- 3連複も順不同で照合
- 馬単・3連単は着順を維持して照合
- 保存済み買い目の全券種・全点を照合し、複数的中を合算
- 100円あたりの払戻を購入金額に応じて換算
- JRA_Bet_History.csvの「結果・回収額・収支」を自動更新
- 同じ予測ログの成績履歴にも自動反映
- 既存の10/04実戦ログ集計除外ルールは維持
- 予想ロジック、買い目生成、実オッズ取得、予算配分など既存部分は変更していません

## 今回の確認対象
例えば保存買い目が

`ワイド 15-14 1,300円`

結果が

`14-15` / 450円

の場合、

`1,300 ÷ 100 × 450 = 5,850円`

として回収額へ反映します。

## 注意
既存CSVの列構成は維持しています。複勝の保存列が既存仕様上独立していないため、複勝は従来どおり「コピペ用買い目」からも照合します。

`python -m py_compile app.py` 済み。
