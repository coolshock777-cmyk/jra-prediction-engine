# JRA Prediction Engine Ver.2.49 LIVELOG BETFORM v3

## 今回の改良
- 既存の予想・ポイント計算は変更しない。
- 5シチュエーション別の買い目フォーメーションを維持。
- netkeiba のリアルタイムオッズAPIから、単勝・複勝・馬連・ワイド・馬単・3連複・3連単の実オッズ取得を追加。
- 組合せ券種は買い目キーを正規化して個別オッズを表示。
- 実オッズ取得済みの券種は、低オッズ側を厚くする傾斜配分へ自動調整。
- 券種別の基本予算枠は5パターンの仕様を維持。
- 総予算は既存UIから変更可能。個別購入額も100円単位で変更可能。
- 未取得オッズは「-」として扱い、架空のオッズは生成しない。
- 保存時は画面上で最終確定した購入額を買い目履歴へ保存。
- 2026/10/04以前のテストログをCSVに保持し、実戦成績集計から除外する既存仕様は変更しない。

## オッズ取得元
組合せ券種のライブオッズは netkeiba の `api_get_jra_odds.html` を利用します。券種コードは 1=単複、4=馬連、5=ワイド、6=馬単、7=3連複、8=3連単です。

発売前・未掲載・通信失敗等で取得できない場合は、推測値や単勝オッズからの代用値を入れません。
