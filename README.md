# JRA Prediction Engine Ver.2.49 LIVELOG BETFORM v5

## 今回の修正
- 既存の出走馬取得・ポイント計算・予想ロジックは変更しない。
- 買い目の5シチュエーション判定だけを改良。
- 旧版の固定14.5%基準を廃止し、出走頭数に応じた相対基準へ変更。
- ◎○の拮抗度、上位4頭の分散、特注穴ポイントを組み合わせて②〜⑤も適切に選択。
- 実オッズ取得・資金配分・手動金額変更・CSV保存の既存機能は維持。

## v6 予想ロジック見直し

今回のv6では買い目エンジンではなく、上流の予想ポイント評価を見直しました。

- 斤量：レース内中央値との差を相対評価
- 馬体重増減：取得できた場合のみ評価（未発表時は推測しない）
- 脚質：前残り/差し等の展開バイアスと連動
- 馬場適性：内外バイアス、ダート1200m等の既存条件を明示的に評価
- 騎手・調教師：既存のリーディング評価を維持
- 継続騎乗・乗り替わり：既存評価を維持
- 騎手/調教師×競馬場・距離・コース：既存評価を維持
- 特注穴：Value Indexだけで決めず、上記の予想因子が複数重なる馬を拾いやすく調整
- ④「2頭拮抗」の判定を厳しくし、全レースが④へ寄るのを抑制
- シチュエーション①〜⑤の買い目エンジンは変更せず、上流の判定結果を渡す

※ 馬体重増減は現在のレースカードから取得できた場合だけ使用します。取得できない開催/時点では、その項目は0点です。
