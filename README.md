# JRA Prediction Engine Ver.2.49 LIVELOG BETFORM v7

Ver.2.49 LIVELOG v6をベースに、結果・払戻の自動照合を追加した版です。

## 今回の追加
- netkeibaの払戻表から単勝・複勝・馬連・ワイド・馬単・3連複・3連単を正規化
- 保存済み買い目の各点（金額付き）と実払戻を全点照合
- 複数券種・複数点の的中を合算
- 100円あたりの払戻を購入金額に応じて換算
- JRA_Bet_History.csvの「結果・回収額・収支」を自動更新
- 同じ予測ログの成績履歴にも自動反映
- 既存の10/04実戦ログ集計除外ルールは維持

## 注意
既存CSVの列構成は維持しています。複勝の保存列が既存仕様上独立していないため、複勝は「コピペ用買い目」からも照合できるようにしています。
